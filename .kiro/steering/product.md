# Product Overview

LiveKit Flutter SDK is a client SDK for building real-time video, audio, and data applications using Flutter. It enables developers to create multi-modal AI applications, live streaming, and video calling features by connecting to LiveKit Cloud or self-hosted servers.

## Key Features
- Real-time video and audio communication
- Cross-platform support (iOS, Android, Web, macOS, Windows, Linux)
- Screen sharing capabilities
- End-to-end encryption (E2EE)
- Audio visualization and processing
- Data streaming and RPC support
- Participant management and room controls

## Target Use Cases
- Video conferencing applications
- Live streaming platforms
- Multi-modal AI applications
- Real-time collaboration tools
- Voice/video calling features

The SDK is built on top of WebRTC and provides Flutter-specific abstractions for managing rooms, participants, tracks, and media streams.
